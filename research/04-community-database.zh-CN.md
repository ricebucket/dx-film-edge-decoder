# 04 – 社区胶片数据库

**问题**：社区来源能否填补 2008 年的年度报告留下的空白，它在多大程度上可信？

**简短回答**：The Big Film Database 涵盖了 637 个可能出现在片边上的 DX 码，其中 277 个不在 2008 年的年度报告中，包括如今仍在销售的大多数胶片。这一计数不包括第 1 部分为 0 的编号：它们按该标准有效，但 2008 年时没有分配给任何感光厂。它采用开放许可证（CC BY-SA 4.0），自带可信度和供应情况字段，但它主要依据暗盒建立，并且有少量不一致之处。

## 它是什么

The Big Film Database 由署名为“Dxdatabase”的作者于 2018 年 2 月以网站形式创办。2024 年，这些数据以 CC BY-SA 4.0 许可证在 GitHub 上发布。该仓库的 README 另外说明，胶片包装盒图片的版权归各自的所有者，这些图片只能在“fair use”（合理使用）下使用。Antoine Mérino 维护着一个修改版，支持按 DX 码搜索和扫描潜影条码。根据该数据库的帮助页面，它最初依据 2008 年的 I3A 列表编成，后来又补充了从 IS&T 获得的 2011–2014 年 DX 码，以及来自柯达的胶片年表、Tom Philo 的柯达胶片编号对照表、Flickr 上一个关于 DX 码的讨论帖、维基百科的胶片列表、收藏者和制造厂员工的信息。

## 文件

`film_database.csv` 是一个以分号分隔的 CSV 文件，使用标准的双引号转义，每个产品或包装版本占一行。各列的说明见 [data/README.zh-CN.md](../data/README.zh-CN.md#big-film-database--社区数据)；其中有两列的值是代码：`reliability`（可信度，“4=high, 0=low”，即 4 为高、0 为低）和 `Ava`（供应情况），它们的含义来自该网站自己的 PHP 代码。该网站只在条目备注的后面显示可信度，这一行标为“Information / Suspected emulsion”（信息／推测的乳剂），所以它评价的是这条备注（通常是某种贴牌胶片被认为是哪种胶片），而不是条目本身。

## 所用快照

该数据库 GitHub 仓库的提交 `9aa3890`（2026 年 10 月 10 日）：共 8,710 行，其中 1,676 行带有 DX extract 或暗盒条码：1,674 行有“DX extract”（四位数编号），2 行只有暗盒条码。`npm run stats:community-data` 会输出这些数字以及下一张表中的数字；[data/README.zh-CN.md](../data/README.zh-CN.md#更新数据) 说明了如何更新快照。

## 数据质量方面的发现

| 发现 | 行数 |
|---|---|
| DX extract 与 DX full（六位暗盒条码）的中间几位数字不一致；该网站的“similar emulsions”（相似乳剂）搜索把这样的一行列在它的 DX extract 下；有两个条目说明了片边上的潜影条码是哪个编号（Harman Phoenix II，017765：105-3；Power Geek，333098：39-1） | 12 |
| 有 DX extract 而没有暗盒条码；其中有 120 胶片、16 mm 胶片和页片（Kodak Ektar 25 PHR120、KODACHROME 25 Movie 16mm、Vericolor III Type S） | 138 |
| 编号大于 2047，例如编号为 5391 的 CineStill 50D 和 800T 暗盒（电影胶片，没有 DX 潜影条码） | 42 |
| 编号小于 16，所以第 1 部分会是 0：按该标准有效，但 2008 年时没有分配给任何感光厂；其中的暗盒条码（富士 Neopan 和 Acros 的 000000、000004 和 100004，柯尼卡 PAN400 的 000084，ORWO 的 000054）在 DX 码的位置上是 0000、0008 或 0005，而 2008 年的年度报告没有给这些胶片 DX 码，或者给的是另一个（ORWOPAN 400 为 123-3），所以这样的编号很可能只是填充数字 | 14 |
| 字段中含有 HTML 标记（`<i>…</i>`） | 3 |
| 名称后附加了 `#` 搜索标签 | 441 |
| 记录了可信度 | 502（0：5，1：44，2：79，3：289，4：85） |
| 供应情况 | 停产 1,465，不确定是否停产 121，在售 90 |

2008 年年度报告中没有的 277 个编号里，有一个是 88-0。它属于第 1 部分 88：年度报告为 Shanghai General 的四个品牌列出这个第 1 部分时没有给出第 2 部分，而该数据库给这四个品牌记的是 88-0。

有两个结构上的局限，比任何单独一行的问题都更重要：

- **暗盒，而不是胶片**。大多数编号是从暗盒上读取的。贴牌胶片用的是品牌方的暗盒，而潜影条码是由生产这种胶片的工厂曝光的。对原厂自己的胶片来说，两者一致；对贴牌胶片来说，两者通常也一致，但没有任何保证。GB/T 9185-2003 规定，包装其他感光厂胶片的整理厂从感光厂而不是从 PIMA 取得 DX 码（附录 A.3.7）。
- **一个编号，多个名称**。一种热门乳剂会出现在每个销售过它的品牌名下，所以一个 DX 码可能列出几十个条目。

该数据库的网站还会根据 DX extract 所在的范围推测制造厂和胶片类型（这些范围列在其仓库的 `Various documentation/Film type by DX.txt` 中）。网站自己也把这种推测标为“not very accurate”（不太准确），而且有些范围相互重叠：46–127 是“Agfa Gevaert chrome (slide) film”（爱克发反转片），但其中又包含 64–79，即“Kodak Technical film”（柯达技术胶片）。
