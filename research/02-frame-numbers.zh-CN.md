# 02 – 画幅号

**问题**：31 位条码的画幅号识别行里存的是什么？它和胶片边上印的数字有什么关系？

**简短回答**：画幅号和半画幅标志合起来（即画幅号识别行），对整个胶卷上的半画幅位置计数。条码每个画幅印两次，一次在画幅处（`23`），一次在这个画幅与下一个画幅的中点（`23A`）；紧挨在每个条码前面印的数字，指的就是这个条码。片头上印作 `XX`、`X` 和 `00` 的位置从 0 往回倒数，分别存为 61、62 和 63，所以存储的值依次为 61, 61A, 62, 62A, 63, 63A, 0, 0A, 1, 1A, …，直到 60A。

## 为什么每个画幅有两个条码

柯达的专利 US 4,965,628 解释了这种设计：冲洗设备会在每个画幅处的片边上打一个切口，这可能毁掉条码。条码足够短、每个画幅能放下两个，就能保证“at least alternate ones of the multi-field bar code images will always be readable”（多字段条码图像中至少每隔一个总能读出），而缺失的那些“may be reconstructed by interpolation”（可以通过插值重建）。该专利把画幅号识别行描述为“seven bits defining the frame number … defined as half frame intervals”（定义画幅号的 7 位……以半画幅间隔定义），所以一卷 36 张的胶卷有 72 个画幅号。

这种重复与胶片的几何尺寸相符：135 规格胶片每前进一个画幅是 8 个孔距，每个孔距 4.75 mm，共 38 mm，而条码大约每 19 mm 重复一次（alibosworth 的格式参考资料）。GB/T 9185-2003 给出了确切的数字：全画幅距为 38 mm，半画幅距为 19 mm（表 1 中的 Y15 和 Y16），半画幅号 1、1A、2、2A……36、36A 每隔四个孔距印在带潜影条码的一侧片边上，每个半画幅号旁边都有一个条码（§6、§7.1）。

柯达的 EP 0838718 描述了印片机是怎样利用这一点的：柯达的 CLAS35 印片机读取一个画幅号作为参照，再利用条码之间的固定间距推算出每个画幅切口处的画幅号，这样每张印出的照片都能带上它的画幅号。另一种做法是在另一侧片边上使用单独的画幅号条码，富士在 1980 年代末用过这种做法，ISO 1007:2000 把它列为一种可选方式，这是在 1993 年草案之后才加入的（[报告 07](07-history-and-related-markings.zh-CN.md)）。

## 条码周围的印字

根据该专利（图 4），同一画幅内前后两个条码之间隔着一个方向箭头和半画幅号，相邻画幅的条码之间则隔着全画幅号。两张真实胶片的照片证实了这个顺序，印字位于它所指的条码*之前*：

|---|---|
| 维基共享资源，*Dx-film-edge-barcode.jpg*（爱克发，DX 47-1） | `▶22A`、22A 的条码、`23`、…… |
| 维基共享资源，*Kodak Telegraph negativ23a.jpg*（Kodak BW400CN） | `23`、23 的条码（经过实测，见[报告 05](05-reading-real-film.zh-CN.md)）、带箭头的 `23A`、…… |

所以，用户读取一个条码时，紧挨在它左边的肉眼可读的画幅号应当与解码出的画幅号一致。本工具会在片条下方说明这一点，并在条码前面画出这个画幅号，大小与柯达负片上的相同（[报告 05](05-reading-real-film.zh-CN.md#验证解码一张真实负片)）。

该标准还规定，另一侧片边上可以再印一行数字：每隔八个孔距印一个全画幅号 1、2……36，或者印半画幅号，作为可选的单道画幅号条码的一部分（§6；[报告 07](07-history-and-related-markings.zh-CN.md#富士的画幅号条码)）。

## 片头：XX、X、00 和 0

在画幅 1 之前，胶卷上还有几个额外的位置，通常在装片时就损失掉了。GB/T 9185-2003 把画幅号 1 称为“第一个指定的号码”（表 6 注 1），并规定“零画幅前面的画幅号由连续的二进制相减得到”（§7.2.1.5）。因此它的表 5 把 00 列为 63、X 列为 62、XX 列为 61，每个都有一个 A 位置；该标准把这些标签写作“×”和“××”。

- alibosworth 记录的柯达胶片上的印字顺序是 `X, XA, 00, 00A, 0, 0A, 1, 1A, …`（没有核实过位值）。
- Antoine Mérino 把一卷 1998 年的柯达胶卷（DX 79-2）上连续的四个条码解码为 62A、63、63A、0。
- Zint 的生成器接受用标签 `X` 或 `S` 表示 62、`00` 或 `K` 表示 63、`F` 表示 0，它的使用手册也是这样写的。

综合起来：**XX = 61, X = 62, 00 = 63**，6 位字段从 63 绕回 0。普通画幅号是 1 到 60：表 5 到 60A 为止；尽管最长的标准胶卷是 36 张，表 5 仍给出了大于 36A 的画幅号，“以防将来需要这些数字”（§7.2.1.5）。替代标签 S、K 和 F 只有 Zint 有记载；没有查到哪些胶片会印这些标签，所以本工具以“也印作”的形式提到它们，而不把它们归到某个制造厂名下。

| 印字 | 画幅号 | 半画幅标志 |
|---|---|---|
| XX / XXA | 61 | 0 / 1 |
| X / XA | 62 | 0 / 1 |
| 00 / 00A | 63 | 0 / 1 |
| 0 / 0A | 0 | 0 / 1 |
| 1 … 60（及 A） | 相同数字 | 0 / 1 |

## 片边上的画幅号不等于相机的画幅

潜影条码是在工厂里按固定间距曝光的；照片则是后来曝光的，位置由相机决定。alibosworth 指出，两者之间没有固定的相位关系：一张照片可能落在一对 `N`/`NA` 上，也可能横跨 `5A` 和 `6`，或者介于两者之间的任何位置。因此，片边上的画幅号能大致告诉你一张照片在胶卷上的位置，这足以确定各张照片的先后顺序，但不一定等于相机画幅计数器上的数。

## 半格相机

半格相机每 38 mm 曝光两张 18 × 24 mm 的照片，大约每个条码一张。Mérino 建议数位置而不是数画幅：0, 0A, 1, 1A, … 变成半画幅 0, 1, 2, 3, …，也就是 2 × 画幅号 + 标志。柯达的印片机在内部也用同样的编号：在 EP 0838718 中，半画幅 22 变为十进制的 44，22A 变为 45。本工具对画幅 0–60 显示这个“半画幅计数”，对 XX、X 和 00 则不显示。

## 短条码

23 位条码根本没有画幅号识别行（见[报告 01](01-edge-code-format.zh-CN.md)）。使用短条码的胶片照样印有画幅号，但无法从条码中读出，所以本工具对这种胶片不显示画幅号，片条上也不留印画幅号的位置。
