# 02 – 帧号

**问题**：31 位条码的帧号字段里存的是什么？它和胶片边上印的数字有什么关系？

**简短回答**：帧号字段和半帧标志合起来，对整个胶卷上的半帧位置计数。条码每帧印两次，一次在帧处（`23`），一次在到下一帧的中点（`23A`）；紧挨在每个条码前面印的数字，指的就是这个条码。片头上印作 `X` 和 `00` 的位置分别存为 62 和 63，所以计数依次为 …, 62, 62A, 63, 63A, 0, 0A, 1, …

## 为什么每帧有两个条码

柯达的专利 US 4,965,628 解释了这种设计：冲洗设备会在每一帧处的片边上打一个切口，这可能毁掉条码。条码足够短、每帧能放下两个，就能保证“at least alternate ones of the multi-field bar code images will always be readable”（多字段条码图像中至少每隔一个总能读出），而缺失的那些“may be reconstructed by interpolation”（可以通过插值重建）。该专利把帧号字段描述为“seven bits defining the frame number … defined as half frame intervals”（定义帧号的 7 位……以半帧间隔定义），所以一卷 36 张的胶卷有 72 个帧号。

这种重复与胶片的几何尺寸相符：135 规格胶片每前进一帧是 8 个齿孔、每个 4.75 mm，共 38 mm，而条码大约每 19 mm 重复一次（alibosworth 的格式参考资料）。

柯达的 EP 0838718 描述了印放机是怎样利用这一点的：柯达的 CLAS35 印放机读取一个帧号作为参照，再利用条码之间的固定间距推算出每个帧切口处的帧号，这样每张印出的照片都能带上它的帧号。另一种做法是在另一侧片边上使用单独的帧号条码，富士在 1980 年代末用过这种做法（[报告 07](07-history-and-related-markings.zh-CN.md)）。

## 条码周围的印字

根据该专利（图 4），同一帧内前后两个条码之间隔着一个方向箭头和半帧号，相邻帧的条码之间则隔着整帧号。两张照片在真实胶片上证实了这个顺序，印字位于它所指的条码*之前*：

![片边上的两个编码，每个前面都印着它的帧号：先是 23，然后是 23A](img/film-edge.zh-CN.svg)

| 照片 | 沿片边从左到右能看到的内容 |
|---|---|
| 维基共享资源，*Dx-film-edge-barcode.jpg*（爱克发，DX 47-1） | `▶22A`、22A 的条码、`23`、…… |
| 维基共享资源，*Kodak Telegraph negativ23a.jpg*（柯达 BW400CN） | `23`、23 的条码（经过实测，见[报告 05](05-reading-real-film.zh-CN.md)）、带箭头的 `23A`、…… |

所以，用户读取一个条码时，紧挨在它左边的片边数字应当与解码出的帧号一致。本工具会在片条下方说明这一点，并画出这些印字。

## 片头：X、00 和 0

在第 1 帧之前，胶卷上还有几个额外的位置，通常在装片时就损失掉了。

- alibosworth 记录的柯达胶片上的印字顺序是 `X, XA, 00, 00A, 0, 0A, 1, 1A, …`（没有核实过位值）。
- Antoine Mérino 把一卷 1998 年的柯达胶卷（DX 79-2）上连续的四个条码解码为 62A、63、63A、0。
- Zint 的生成器接受用标签 `X` 或 `S` 表示 62、`00` 或 `K` 表示 63、`F` 表示 0，它的使用手册也是这样写的。

综合起来：**X = 62, 00 = 63**，6 位字段从 63 绕回 0。1–61 是普通帧号。替代标签 S、K 和 F 只有 Zint 有记载；没有查到哪些胶片会印这些标签，所以本工具以“也印作”（also printed as）的形式提到它们，而不把它们归到某个生产商名下。

| 印字 | 帧号字段 | 半帧标志 |
|---|---|---|
| X / XA | 62 | 0 / 1 |
| 00 / 00A | 63 | 0 / 1 |
| 0 / 0A | 0 | 0 / 1 |
| 1 … 61（及 A） | 相同数字 | 0 / 1 |

## 片边数字不等于相机帧号

片边码是在工厂里按固定间距曝光的；照片则是后来曝光的，位置由相机决定。alibosworth 指出，两者之间没有固定的相位关系：一张照片可能落在一对 `N`/`NA` 上，也可能横跨 `5A` 和 `6`，或者介于两者之间的任何位置。因此，片边数字能大致告诉你一张照片在胶卷上的位置，这足以给各帧排序，但不一定等于相机帧计数器上的数。

## 半格相机

半格相机每 38 mm 曝光两张 18 × 24 mm 的照片，大约每个条码一张。Mérino 建议数位置而不是数帧：0, 0A, 1, 1A, … 变成半帧 0, 1, 2, 3, …，也就是 2 × 帧号 + 标志。柯达的印放机在内部也用同样的编号：在 EP 0838718 中，半帧 22 变为十进制的 44，22A 变为 45。本工具对帧 0–61 显示这个“半帧计数”，对片头的值则不显示。

## 短条码

23 位版式根本没有帧号字段（见[报告 01](01-edge-code-format.zh-CN.md)）。使用短条码的胶片照样印有帧号，但无法从条码中读出，所以本工具对这种胶片不显示帧号。
