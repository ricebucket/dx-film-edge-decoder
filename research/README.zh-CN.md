# 研究笔记

这些报告记录了为本项目研究 DX 片边条码时的发现：编码如何排布，其中的数字代表什么，胶片数据从哪里来，以及每个来源在多大程度上可信。每篇报告开头先给出简短的回答，并在相关的地方注明尚未解决的问题。所有来源都只在报告 06 中列出一次。

| [02 – 帧号](02-frame-numbers.zh-CN.md) | 半帧位置、`23A` 这样的片边印字、片头的值 X 和 00、半格相机 |

## 方法

没有哪一个免费来源完整地规定了整个格式：正式标准（ISO 1007，以及美国的历代版本 ANSI PH1.14 → NAPM IT1.14 → PIMA IT3.42）由 ISO 和 ANSI 出售，本项目没有查阅。作为替代，解码器使用的每一条规则，都在柯达的专利、维基百科对 ISO 1007 的概述、两个开源实现（zxing-cpp 和 Zint）以及社区文章中至少有两个相互独立的来源支持，并且在一张真实负片上得到了确认（[报告 05](05-reading-real-film.zh-CN.md)）。胶片数据表用两个相互独立的解析器转录，并与列表本身做了核对（[报告 03](03-dx-numbers-and-registry.zh-CN.md)）。
